Judgement only, no page text.

**Reliable**
- The company's own homepage: clear on product and audience, but no leadership names and no mission statement. Good for "what it does", useless for "who is the CEO".

**Weak**
- Vendor-style funding profiles (e.g. signalbase-type pages): marketing phrasing, no named executives, amounts may differ from press.
- Aggregator snippets (CB Insights, UK company-listing sites): partial, sometimes a different company with a similar name. Leads only.
- MarketScreener-type insider/director data: can conflate similarly named firms. Do not use for CEO.
- Search-engine summaries: they gave the CEO name, but I did not read the underlying page, so it stayed unconfirmed.

**Next time**
- Spend one page read on a funding press article (e.g. pulse2-type) or the About page to confirm the CEO name and title, not on aggregators.
- Prefer press I actually read over summaries; keep unread items marked unconfirmed.
- Funding amounts can differ by currency (GBP vs USD); report both with attribution.
- With only 4 searches, search for the CEO name early, since the homepage rarely lists it.
