# Source vetting

You have a small budget (4 searches, 2 page reads), so choose carefully.

## Rank sources
1. **Primary:** the brand's or organization's own page, official statistics, the original study or announcement.
2. **Reputable secondary:** press that names where its numbers came from.
3. **Aggregators and blogs:** roundups and "guides". Use for background and leads only. Never quote a number from one alone.

## Spot thin or SEO-spam pages
- No author, no date, or a date that looks refreshed ("Updated 2026") with old content.
- Numbers with no citation.
- Wording near-identical to other results. That means copying, so it counts as one source.
- Titles like "The Ultimate Guide", heavy affiliate links, almost no real content.

## Check recency
For things that change fast (platform rules, prices, trends), prefer pages from the last year and say when a source is older. Rule of thumb, not a law.

## Choose what to read
- Read primary pages first. Search snippets can be cut off, so read the page before quoting a number from it.
- If a search returns only blogs, say so plainly.

## Conflicts
If sources disagree, report the range and name each source. Example: "Caption limit: 2,200 (most guides) or 4,000 (two guides); no official page found."

## In the findings
For each fact worth quoting, record the URL, what it supports and what type of source it is (official, press, blog), with the date if known. Mark any figure supported only by blogs as **unconfirmed**. Drop anything with no source and no date. Full rules: `fact-grounding`.
