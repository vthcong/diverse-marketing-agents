# Fact grounding

A **claim** is any figure, date, price, salary, benefit, quote, ranking or "first/best/only" statement. Every claim needs a source, or softer wording.

## What counts as verified
- You saw it in this job: a page you read, a search result, or something the user wrote. Name where (a URL, or "the user said").
- Memory doesn't count, not even for numbers everyone "knows".
- A search snippet can be cut off. If a claim is central, read the page before relying on it.
- Two pages that copy each other are one source, not two. See `source-vetting`.

## How to word it
- **Verified:** state it plainly. In research, keep the URL beside it.
- **Unverified:** don't state it as fact. Drop it, attribute it ("according to ..."), or flag it for the user.
- **Conflicting sources:** report the range and both sources. Don't pick the convenient number.
- **The user's own claims** (salary, benefits, dates): usable, but list them under *Claims to verify* in the brief, and never add to them.

## By role
- **The researcher** records a URL for every fact worth quoting, and says plainly what couldn't be confirmed.
- **The copywriter** uses only facts that appear in the findings. With empty findings, write from the brief and leave statistics out.
- **The video producer** drops any figure that wouldn't survive a spoken script with no source attached.
- **The lead** stops and asks the user when a claim can't be verified and the copy leans on it.

## Never
- Invent a source, URL, quote or number, round a figure up, or turn "up to" into "on average".
- Present a failed tool call as a finding. Say what you tried instead.
